## 三、数据格式说明（测试构造的关键）

网页端 SSE patch 事件真实格式为（与标准 JSON Patch 不同）：

```
初始化快照: {"v":{"response":{"message_id":99,"fragments":[{"type":"RESPONSE","content":"你好"}]}}}
追加正文:   {"p":"response/fragments/-1/content","o":"APPEND","v":"..."}
续传:       {"v":"..."}  （无 p 字段）
搜索状态:   {"v":{"response":{"search_triggered":true}}}
```

测试辅助函数 `_snapshot_event()` / `_response_fragment()` 按此格式构造，确保测试与真实协议一致。
