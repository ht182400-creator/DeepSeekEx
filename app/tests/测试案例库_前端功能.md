# 前端功能测试案例库

被测对象：`app/frontend/`（app.js / actions.js / utils.js / data.js / index.html）

- 测试方式：ego-browser 真实浏览器交互测试（脚本存放于本机临时测试目录，不随仓库分发）
- 测试服务：http://127.0.0.1:20000
- 重要前提：静态 JS 会被浏览器强缓存，测试前必须 `page.cdp("Network.setCacheDisabled", {cacheDisabled:true})` 或 URL 加 `?v=时间戳`，否则测的是旧代码。
- 日志：ego-browser 脚本 stdout 输出 JSON 结果；后端日志 `app/logs/deepseek_app.log`

### FE37 历史项时间显示（2026-11-24）

- 操作：`page.cdp("Network.setCacheDisabled", {cacheDisabled:true})` → 打开 `?v=时间戳` 绕过强缓存 → 读取每个 `.history-item` 内 `.history-item-text` 与 `.history-item-time`，并用 `getBoundingClientRect()` 测量两者 top 坐标
- 预期：时间独占标题**下一行**（`timeRect.top >= titleRect.bottom - 1`），格式为年-月-日 时:分:秒，无效时间不显示
- 实测：5/5 项 `separateLine=true`（如 titleTop=166 / timeTop=188，相差 22px），5/5 格式匹配 `^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$`，例如 `2026-11-23 23:51:27`
- 截图：存于本机临时测试目录（不随仓库分发）
- 关联改动：`utils.js` 新增 `formatFullTime()`；`app.js` `renderHistory()` 用块级 `<div>` 注入时间行；`styles.css` 用 `display:block` 确保分行不依赖 flex 缓存
- 修复记录：首版用 `<span>` + flex column，部分浏览器缓存下仍同行；改用 `<div>` + `display:block` 后 5/5 稳定分行

- 操作：`appState.settings.enhancements.context = true` → `applyEnhancements()` → `updateContextMeter()`

- 说明：文本类附件真实送达模型；二进制文件仅显示名称并明确标注。

## 本轮发现并修复的 bug（FE30）

### 空 model 写入配置

- 复现：设置页模型选择框值意外为空（如脚本注入了下拉框中不存在的选项值）时保存设置
- 现象：后端 `settings.json` 的 `model` 被写成空字符串，读取配置 `model=''`，可能导致后续对话模型参数异常
- 根因：前端 `saveSettings` 直接取 `select.value`（无效值→空字符串）即提交；后端 `update_settings` 无条件写入所有传入字段
- 修复：
  - 前端：`const model = select.value || DEFAULT_MODEL`（`DEFAULT_MODEL='deepseek-flash'`）
  - 后端：`update_settings` 对字符串字段做空值跳过（`if isinstance(value,str) and not value.strip(): continue`）
- 验证：修复后 `POST /api/settings {"model":""}` → 读取配置 `model` 仍为 `deepseek-flash`（FE30 PASS）
