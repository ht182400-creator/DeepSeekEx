# 优化版（增强层）设计说明

> 对应实现：`app/frontend/`（增强功能作为可开关层叠加在 1:1 复刻 UI 上）
> 设计依据：`01_DeepSeek产品分析报告.md` 第六章

---

## 一、设计原则

**核心原则：以 1:1 复刻为基础做加法，不另起炉灶。**

早期我做过一个"另建新 UI"的独立优化版，用户指出这偏离了需求——用户要的是"1:1 复刻 + 扩展"，不是换一套皮。因此最终形态收敛为：

```
1:1 复刻的 DeepSeek UI（原样保留）
    +
可开关的增强层（设置里控制显隐）
    +
真实的双 Provider 后端（对话不再 offline）
```

---

## 二、增强功能清单

### 1. 会话标签筛选 + 收藏
- 会话可标记 work/study/life 标签（侧边栏色点标识）
- 筛选栏：全部/收藏/工作/学习
- 星标收藏、侧边栏搜索框实时过滤

### 2. 分屏对比模式
- 双栏工作区，同一问题用不同策略回答
- 适合 A/B 测试提示词、对比回答质量

### 3. 提示词库 + 快捷指令
- 内置 9 个模板（写作 3/编程 3/学习 3）
- 抽屉式弹层，点击填入输入框
- 欢迎页快捷卡片

### 4. 专注模式
- 一键隐藏侧边栏与工具栏，进入沉浸式对话

### 5. 上下文用量可视化
- 顶部实时显示 token 估算
- 渐变进度条，超过 80% 变红警告

### 6. 模型/模式选择器
- 快速模式 / 专家模式 / 代码模式

### 7. 对话导出 Markdown
- 一键导出当前对话为标准 Markdown

### 8. 深色主题 + 速度设置
- 深色模式、上下文条开关、流式输出速度三档

## 四、视觉设计差异（克制原则）

| 维度 | 原版 | 增强后 |
|------|------|--------|
| 主色 | DeepSeek 蓝 | 保持一致，不引入第二主色 |
| 顶栏 | 三图标 | 原样保留 + 增强工具按钮（小图标，不抢视觉） |
| Provider 状态 | 无 | 新增徽章，显示"官方 API"/"网页登录态" |
| 设置 | 用户菜单内 | 顶栏齿轮图标 + 完整设置弹层 |
| 欢迎页 | 标语 + 输入框 | 保持原样，不加快照卡（避免偏离原站） |

**克制**：增强功能以"不破坏 1:1 复刻观感"为前提，能收进设置就不放主界面。

## 五、保留的原版核心体验

- 鲸鱼品牌标识与蓝色主色调
- 深度思考 / 智能搜索双模式芯片

- 联网搜索卡片与引用角标
- Markdown 正文 + 代码块
- 来源聚合卡
- 复制/重新生成/赞踩/朗读/分享操作栏
- Ctrl+J 新对话
